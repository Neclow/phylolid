# Datasets

The `datasets` directory should contain the following subdirectories, one per
multilingual text corpus:

- `glotlid-corpus`: GlotLID-C, the training corpus of GlotLID
  ([arXiv:2310.16248](https://arxiv.org/abs/2310.16248)). Gated: needs a Hugging
  Face token with access. Obtained via `pipeline/download_glotlid.py`.
- `omnilingual-asr`: transcripts of the Omnilingual ASR corpus (CC-BY-4.0,
  [arXiv:2511.09690](https://arxiv.org/abs/2511.09690)), split into sentences.
  Obtained via `pipeline/download_omnilingual.py`.

Each of these dataset directories should be formatted as follows:

- `<version>`: dataset version (`v3.1` for GlotLID-C; the short hash of the
  Hugging Face commit for Omnilingual ASR, which has no version of its own)
  - `<label>`: one folder per label, named `<ISO 639-3>_<script>` (e.g.
    `kal_Latn`)
    - `<label>_<source>.txt` (GlotLID-C) or `<label>.tsv` (Omnilingual ASR, one
      sentence per row)

## Files

- `glottolog.csv`: every dataset label (column `dataset`) with its script,
  Glottolog languoid and lineage (`H0` = top-level family). Generated by
  `pipeline/map_glottolog.py`.
